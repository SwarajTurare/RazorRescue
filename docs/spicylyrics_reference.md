# Spicy Lyrics-inspired motion note

The home-page background borrows the *concept* of a music/lyrics experience: slow, blurred, blended color fields that create a live ambient layer behind centered content. It is implemented from scratch in `KineticBackground.jsx`.

No Spicy Lyrics source code, logos, images, or proprietary assets are included. The visual effect is intentionally adapted to RazorRescue's dark blue/magenta product palette.
